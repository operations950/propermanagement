Booking calendars

Paste a listing's Airbnb or VRBO calendar link and the app checks it every {{ poll_minutes }} minutes: new reservations get a turnover visit (and calendar event), changed dates move it, and a reservation that has disappeared from the calendar is cancelled once it has been missing for {{ missing_polls }} checks in a row. Uploading a CSV still works alongside this — it adds guest and listing detail, and the same reservation is never counted twice. Each link is private (anyone with it can read that calendar), so it is stored encrypted and only shown partly hidden. Where to find it: in each platform's calendar settings for that listing, look for Export calendar (an .ics / iCal link).
