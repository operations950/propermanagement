Booking calendars

Every short-term rental gets an Airbnb line and a VRBO line (one pair per unit for a building). Paste that listing's calendar link and the app checks it every {{ poll_minutes }} minutes: new reservations get a turnover visit and calendar event, changed dates move it, and a reservation that has disappeared is cancelled once it has been missing for {{ missing_polls }} checks in a row. If a property isn't on a platform, mark it Not listed so it stops being flagged. General placeholders (like "Short-Term Rentals (general)") never appear here and never get visits. Each link is private, so it is stored encrypted and shown only partly hidden. Where to find it: the listing's calendar settings on the platform — look for Export calendar (an .ics link). CSV uploads still work alongside this.
